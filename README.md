# Bone Crypt

A 3D arena brawler for the browser. Smash skeletons into bone piles, then shatter the piles before they rise again.

Play: https://unuenxiwksueowornwuxjruwo.github.io/bone-crypt/

Built with three.js (MIT). Characters, animations and props: KayKit by Kay Lousberg (CC0). Audio credits: `audio/CREDITS.txt`.
